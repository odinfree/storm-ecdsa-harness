# Names

Every skill, tool, script and note in this repository has a Swiss German name beside its technical id. The ids
stay as they are, so installs and agents keep working: a skill is loaded by its folder name and frontmatter
`name`, a tool is called by its file name. The Swiss name is in the title of each SKILL.md and tool README.
This file is the single map; `scripts/names-check.py` checks that it is complete and that no name is used
twice.

Spelling follows no standard, as Swiss German has none. Tool folders use ASCII (`ue` for `ü`, `ae` for `ä`,
`oe` for `ö`).
